# AI API 中转站大全

一个全面收集和整理 AI API 中转站信息的项目，帮助开发者选择合适的中转服务。

## 📋 项目简介

随着 AI 大模型的普及，各种 API 中转站应运而生。本项目旨在：

- 📊 收集整理 **150+** 个 AI API 中转站信息
- 🔍 提供详细的倍率、模型支持、运营时间等数据
- 📈 按规模分类，从大到小全面覆盖
- 🆓 包含开源中转方案

## 🚀 快速开始

### 查看中转站列表

1. **大型中转站**：稳定可靠，适合企业级应用
2. **中型中转站**：性价比高，适合个人开发者
3. **小型中转站**：新兴平台，可能有特殊优惠
4. **开源方案**：自建中转，完全掌控

### 数据格式

每个中转站包含以下信息：

| 字段 | 说明 |
|------|------|
| 名称 | 中转站名称 |
| 网址 | 官方网站地址 |
| 支持模型 | 支持的 AI 模型列表 |
| 倍率 | 相对于官方价格的倍率 |
| 运营时间 | 中转站运营时长 |
| 备注 | 其他重要信息 |

## 📊 中转站对比

### 倍率参考

| 倍率范围 | 说明 |
|----------|------|
| 1.0 | 与官方价格相同 |
| 1.0-1.3 | 略高于官方价格 |
| 1.3-1.5 | 中等溢价 |
| 1.5+ | 较高溢价 |

### 选择建议

- **稳定性优先**：选择大型中转站
- **价格优先**：比较各站倍率
- **模型覆盖**：确认支持所需模型
- **地理位置**：考虑访问速度

## 🔧 开源自建方案

对于需要完全掌控的用户，推荐以下开源方案：

1. **sub2api** - 一站式开源中转服务
2. **new-api/one-api** - 开源中转网关
3. **其他开源项目** - 详见 `docs/open-source/`

## 📝 使用说明

### 如何选择中转站

1. **确定需求**：需要哪些模型？预算多少？
2. **比较倍率**：选择性价比最高的方案
3. **测试稳定性**：先小规模测试
4. **查看评价**：参考其他用户反馈

### 注意事项

- 倍率可能随时间变化，请以官网为准
- 部分中转站可能有地区限制
- 建议先小额测试再大规模使用
