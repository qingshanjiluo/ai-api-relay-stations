# 开源中转方案

开源中转方案适合需要完全掌控的用户，可以自建中转服务。

## 📊 开源项目列表

### 1. sub2api

**基本信息**
- **名称**：sub2api
- **GitHub**：https://github.com/Wei-Shaw/sub2api
- **Stars**：41,290+
- **语言**：Go
- **许可证**：LGPL-3.0

**功能特点**
- 一站式开源中转服务
- 支持 Claude、OpenAI、Gemini、Grok 订阅统一接入
- 支持拼车共享，更高效分摊成本
- 原生工具无缝使用
- 支持多种模型

**技术架构**
- 基于 Go 语言开发
- 高性能并发处理
- 支持集群部署
- 提供 Web 管理界面

**适用场景**
- 需要自建中转服务
- 多人共享 API 额度
- 需要完全掌控
- 技术团队使用

**部署要求**
- Go 环境
- 服务器资源
- 域名和 SSL 证书
